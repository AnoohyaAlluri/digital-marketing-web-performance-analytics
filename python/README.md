# Python Analysis

Python will support recurring analytical work that benefits from
reproducible code, including:

-   Data validation
-   Exploratory analysis
-   Period-over-period comparisons
-   Segmentation
-   Statistical analysis
-   Confidence intervals
-   Categorical tests where appropriate
-   Trend analysis
-   Reusable reporting outputs

Python is an analytical layer---not a replacement for SQL
transformations or Power BI reporting.
