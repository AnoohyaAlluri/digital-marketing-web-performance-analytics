# Measurement Framework

## Funnel

``` text
Digital Discovery
→ Website Visit
→ Engagement
→ High-Intent Interaction
→ Inquiry
→ Validated Lead
→ Qualification / Follow-Up
→ Available Downstream Outcome
```

## Measurement Domains

### Acquisition

Traffic source, campaign, channel, landing entry, paid-media activity.

### Website Behavior

Landing-page behavior, engagement, CTA interaction, form behavior,
high-intent events.

### Conversion

Primary and secondary conversion actions with explicit definitions.

### Lead Validation

Determines whether captured submissions represent meaningful prospective
demand.

### Lead Progression

Measures available evidence after initial acquisition without inventing
missing lifecycle stages.

### Outcome Measurement

Uses only verified downstream evidence.

## Recurring Comparison

Each 3--4 month cycle should compare the current period with an
appropriate prior period while clearly identifying partial periods,
seasonality risks, data-definition changes, and tracking changes.

## Measurement Health

Every review should also ask whether tracking itself changed. A
performance change can reflect business behavior, marketing behavior,
website behavior, or measurement behavior.
