# Growth Recommendation Framework

Recommendations should follow evidence rather than precede it.

## Recommendation Categories

### Measurement

Tracking QA, event definitions, conversion definitions, UTMs, lifecycle
fields, source governance.

### Website / CRO

Landing pages, CTAs, form friction, high-intent paths, conversion
journeys.

### Acquisition

Channel investigation, campaign measurement, source quality, audience or
query opportunities.

### Lead Management

Follow-up visibility, lifecycle tracking, qualification definitions,
routing and response measurement.

### Experimentation

Clearly defined hypothesis, variable, KPI, analysis window, and success
criteria.

### Reporting

Dashboard improvements, metric definitions, recurring comparisons,
exception monitoring.

## Recommendation Template

**Evidence:** What was observed?\
**Problem:** What business or measurement issue does it create?\
**Recommendation:** What should change or be tested?\
**Expected Signal:** What metric should respond if the recommendation
works?\
**Validation:** How will the next 3--4 month cycle determine whether it
helped?\
**Status:** Recommendation / In Progress / Validated / Needs More Data.
