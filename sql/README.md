# SQL Layer

Planned SQL workflow:

1.  Create schemas/tables
2.  Load synthetic raw data
3.  Standardize website and marketing fields
4.  Validate lead intent
5.  Deduplicate prospects
6.  Build acquisition-source views
7.  Analyze paid-media performance
8.  Build funnel/outcome linkage
9.  Run validation checks
10. Create reporting views

The SQL should remain readable, business-rule driven, and traceable
rather than artificially complex.
